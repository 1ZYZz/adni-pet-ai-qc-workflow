# Public results folder

This folder is for manuscript-level aggregate outputs only.

Current included file:

- `Table1_metrics_for_summary.csv`: aggregate metrics from the manuscript workflow.

Do not place raw ADNI tables, locked cohort spreadsheets, scan-level SUVR/Z-score tables, or individual-level QC rows here unless your data-use agreement explicitly allows redistribution.

Manuscript figures can be added after checking journal/conference and data-use policies.
